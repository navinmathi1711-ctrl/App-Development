## 🚀 Getting Started

Each project folder contains its respective source files and configuration.

- **Static Projects (1, 2, 3)**:
  Open the respective `index.html` or `.html` file directly in your browser.

- **Node.js Projects (4, 5, 6)**:
  Open the respective project folder in your terminal, install dependencies, and run:
  ```bash
  npm install
  npm run dev   # or npm start
  ```
